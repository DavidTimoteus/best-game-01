Grid Prism: Polarity Protocol is a high-performance 2D Canvas vector arcade roguelike built for the [make.fun](https://make.fun/bounty/best-game-01) "Make the best game" bounty ($1,000 USDC).

## Features
- **Original Vector Aesthetic:** Glowing high-contrast neon lines, chromatic HUD, and responsive vector rendering.
- **Harmonic Polarity Mechanic:** Dynamically shift frequencies between Cyan (440 THz) and Amber (880 THz) to harmonize with incoming energy nodes and defuse matching hazard barriers.
- **Tactical Movement & Chrono-Dash:** High-speed agility with invulnerability window to puncture dense hazard clusters and confront the Sector 4 Singularity Nexus Boss.
- **Zero-Dependency Self-Contained Engine:** 100% pure vanilla ES modules, custom procedural Web Audio API synthesizer, and zero external network calls.
- **Lauren Tan Architecture:** Decoupled 60 FPS fixed-step physics, deterministic screenshot staging, and object-pooled particle engines.

## Controls
- **Maneuver:** `W`, `A`, `S`, `D` or `Arrow Keys`
- **Shift Polarity:** `Shift` or `Q`
- **Chrono-Dash:** `Space` or `Left Mouse Click`
- **Reboot Simulation:** `R`
